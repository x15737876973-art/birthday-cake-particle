# 🎂 3D 粒子蛋糕

祝 郝文君宝宝 生日快乐！

打开就能看：<https://x15737876973-art.github.io/birthday-cake-particle/>

## 玩法

- 整块蛋糕、蜡烛、火焰、托盘全部由约 4 万个发光粒子构成，缓慢自转
- 鼠标拖拽旋转 / 滚轮缩放（手机上单指拖拽）
- **吹蜡烛**：对着麦克风吹气、直接点击蜡烛，或点「🌬️ 吹蜡烛」
- 三根蜡烛全灭 → 蛋糕炸散成烟花，粒子重新排列成「郝文君 · 生日快乐 · HAPPY BIRTHDAY」
- 「✨ 粒子祝福」文字形态 ｜「🎁 许愿」爱心 / 星环
- 音效全部由 WebAudio 实时合成，无外部依赖，单个 HTML 文件即可运行

## 本地使用

直接双击 `index.html` 即可（推荐 Chrome / Edge / Safari 新版）。
麦克风吹气需要 https 或 localhost，本地文件打开时用点击蜡烛同样可以吹灭。
